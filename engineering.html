This season's Valley X robot

Last season's robot took too many steps to do simple things. So this year, every decision answers to five requirements:

  • Simplicity
  • Speed
  • Reliability
  • Accuracy
  • Coding ease

Strategy

We score only in the hive. It's faster than the alternatives and earns a ranking point.

Turret shooter

We compared four shooter concepts and chose a dual-turret design for speed. A 6,000 RPM goBILDA motor drives four flywheels, with added steel mass so speed holds from the first shot to the last.

Aim from anywhere

A gear-driven goBILDA turret gives 332° of rotation with no belts or custom parts. The hood angle comes from a projectile-motion equation, so one launch speed scores from anywhere on the field.

Drivetrain

Four 435 RPM motors on mecanum wheels let the robot strafe and line up a shot from any angle.

Smart intake

Beam-break sensors count game pieces. At four, the intake shuts off and the shooter spins up, so the two never run at once.

Autonomous

A goBILDA Pinpoint tracks position and heading all match long. A Limelight reads AprilTags to aim the turret, with trigonometry from our position as the fallback. One base auto mirrors for either alliance, so we can write a new routine for a partner fast.

Software

Tools we built, and share

ValleyLib

Open source

A command-based robotics library for FTC and FRC. Traditional FTC code runs everything through one giant loop, so adding a mechanism means touching everything. In ValleyLib, each mechanism is a subsystem, each action is a command, and a scheduler keeps two commands from fighting over the same motor. It also supports Pedro Pathing, which FTCLib doesn't.

  • 20 → 4lines for a typical action
  • 66automated tests that run on a laptop
  • 5,000+lines of code

Apex Scout

Scouting app

Our scouting app works fully offline and moves data between devices with QR codes. A dashboard combines weighted rankings with official FIRST data, and a pit display tells teams when to queue. Each team's data is private to that team.

  • 70+users
  • 10+teams
  • 0internet needed. Used at AZ State and Western Edge

All of our code is public at github.com/ValleyX.
